# FlowLab

An explainable 2D fluid-flow research prototype built around the viscosity/diffusion component of Navier–Stokes.

## Run

This application is designed for the Next/Vinext starter. Install dependencies, then run the development server.

## Scope

This is not a claim to solve the general 3D Navier–Stokes problem. It exposes assumptions, parameters, and numerical results so the model can be tested before adding advection and pressure projection.

Live demo: https://flow-lab-research.carinengeny.chatgpt.site
